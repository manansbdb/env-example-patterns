# Guidelines / Diretrizes

## English
- Commit `.env.example`, ignore `.env` / `.env.local`.
- Use obvious placeholders (`change-me`, `USER`, `PASSWORD`).
- Group related variables and comment purpose.
- Prefer `DATABASE_URL` style when the runtime supports it.
- Document required vs optional vars in README.

## Português
- Faça commit de `.env.example`; ignore `.env` / `.env.local`.
- Use placeholders óbvios (`change-me`, `USER`, `PASSWORD`).
- Agrupe variáveis relacionadas e comente o propósito.
- Prefira estilo `DATABASE_URL` quando o runtime o suportar.
- Documente variáveis obrigatórias vs opcionais no README.
