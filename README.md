# .env.example Patterns / Padrões de .env.example

Safe patterns for environment example files (no real secrets).

Padrões seguros para ficheiros de exemplo de ambiente (sem segredos reais).

## English

Use `.env.example` as the documented contract of required variables. Never commit real credentials.

## Português

Use `.env.example` como contrato documentado das variáveis necessárias. Nunca faça commit de credenciais reais.

## Files / Ficheiros
- `examples/.env.example` — sample / exemplo
- `guidelines.md` — do/don't / boas práticas
